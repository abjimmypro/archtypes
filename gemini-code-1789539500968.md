# Service 2 Refactoring & Production Readiness Specification

## Executive Summary
This document specifies the Phase 1 stability fixes and architectural roadmap for **Service 2**. The goal is to safely process **50–60 documents/hour** across **4–5 OpenShift (OCP) Pods** (500m–700m CPU request / 8 vCPU limit, 5 GiB RAM limit per pod) without triggering Kubernetes Out-Of-Memory (`OOMKilled`) crashes, OkHttp connection bottlenecks, or thread starvation.

---

## System Architecture & Capacity Limits

* **Pipeline Sequence:** S3 File → Service 1 → Stream to Service 2 → Doc AI Layout Batch → Doc AI OCR Batch → PDFBox Page Split → Layout JSON Page Split → Parallel Spring AI 2.0.1 Calls (30–40 pages) → External Python Overlay HTTP Service → Aggregate Pages → MongoDB Save + Response.
* **Latency Envelope:** ~10–12 minutes total duration per document.
* **Resource Allocations per OCP Pod:** 
  * **CPU Request / Limit:** 500m / 8 vCPU (Bursts allowed for PDF splitting/overlays)
  * **Memory Request / Limit:** 5 GiB / 5 GiB
  * **JVM Memory Floor:** `-Xmx3500m -Xms3500m` (Leaves ~1.5 GiB for non-heap, Metaspace, and OS)
  * **Pod Concurrency Limit:** **3 active documents** (or ~100 in-flight pages) maximum per pod.
  * **Cluster Throughput:** 5 Pods × 3 slots = 15 active jobs ≈ **55–60 docs/hour**.

---

## Phase 1: Production Survival (Immediate Implementation)

### 1. Spring AI 2.0.1 OkHttp Dispatcher Customization
**Issue:** Spring AI 2.0.1 utilizes OpenAI's Java SDK over OkHttp. OkHttp defaults to `maxRequestsPerHost = 5`, forcing 30 parallel page requests into 6 sequential batches (adding ~10 minutes of artificial delay).  
**Fix:** Uncap the OkHttp dispatcher host limit via `OpenAiHttpClientBuilderCustomizer`.

```java
package com.example.config;

import okhttp3.Dispatcher;
import org.springframework.ai.autoconfigure.openai.OpenAiHttpClientBuilderCustomizer;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class OkHttpConfig {

    @Bean
    public OpenAiHttpClientBuilderCustomizer customOkHttpDispatcher() {
        return builder -> {
            Dispatcher dispatcher = new Dispatcher();
            dispatcher.setMaxRequests(300);
            dispatcher.setMaxRequestsPerHost(150); // Unlocks parallel LLM calls to same host
            builder.dispatcher(dispatcher);
        };
    }
}

```

### 2. PDFBox Memory Offloading to Container Disk

**Issue:** Loading 500-page PDFs into the JVM heap consumes 1–2 GB RAM per active document, causing container OOM crashes.

**Fix:** Configure PDFBox to offload memory buffers to pod scratch disk.

```java
import org.apache.pdfbox.io.MemoryUsageSetting;
import org.apache.pdfbox.pdmodel.PDDocument;
import org.apache.pdfbox.Loader; // PDFBox 3.x

public PDDocument loadPdfSafely(byte[] pdfBytes) throws IOException {
    // Write stream buffers to disk instead of JVM heap
    return Loader.loadPDF(pdfBytes, MemoryUsageSetting.setupTempFileOnly());
}

```

### 3. Resilience4j Pod Bulkhead

**Issue:** Accepting uncontrolled incoming jobs causes pod heap memory to exceed 3.5 GiB.

**Fix:** Enforce a hard bulkhead limit of 3 concurrent document pipelines per pod.

```yaml
# application.yml
resilience4j.bulkhead:
  instances:
    documentPipeline:
      maxConcurrentCalls: 3
      maxWaitDuration: 0 # Fail fast or defer queue acknowledgment when full

```

## Non-Invasive AOP Tracing & JSON Audit Logging

To track step durations, parent-child contexts, page metrics, and exceptions **without adding Prometheus collector overhead or polluting core business logic**, implement a Spring AOP aspect.

### Step 1: `@TrackStep` Annotation

```java
package com.example.tracing;

import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;

@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @annotation TrackStep {
    String value() default ""; // Step identifier (e.g., "DOC_AI_LAYOUT", "LLM_PAGE_EXTRACTION")
}

```

### Step 2: Job Execution Summary Model

```java
package com.example.tracing;

import lombok.Data;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.CopyOnWriteArrayList;

@Data
public class JobExecutionSummary {
    private final String documentId;
    private final String clientId;
    private final String useCaseId;
    private final long startTime = System.currentTimeMillis();
    private long totalDurationMs;
    private String status = "SUCCESS";
    private final Map<String, Long> stepDurationsMs = new ConcurrentHashMap<>();
    private final List<Map<String, String>> errors = new CopyOnWriteArrayList<>();

    public void recordStep(String stepName, long durationMs, String stepStatus, String errorDetails) {
        stepDurationsMs.merge(stepName, durationMs, Long::sum); // Aggregates repeated calls (e.g., 30 LLM pages)
        if ("FAILED".equals(stepStatus)) {
            this.status = "FAILED_WITH_ERRORS";
            if (errorDetails != null) {
                this.errors.add(Map.of("step", stepName, "error", errorDetails));
            }
        }
    }

    public void complete() {
        this.totalDurationMs = System.currentTimeMillis() - startTime;
    }
}

```

### Step 3: AOP Tracing Aspect

```java
package com.example.tracing;

import com.fasterxml.jackson.databind.ObjectMapper;
import lombok.extern.slf4j.Slf4j;
import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.Around;
import org.aspectj.lang.annotation.Aspect;
import org.springframework.stereotype.Component;

@Aspect
@Component
@Slf4j
public class JobTracingAspect {

    private static final ThreadLocal<JobExecutionSummary> CURRENT_JOB = new ThreadLocal<>();
    private static final ObjectMapper OBJECT_MAPPER = new ObjectMapper();

    public static void startJob(String docId, String clientId, String useCaseId) {
        CURRENT_JOB.set(new JobExecutionSummary(docId, clientId, useCaseId));
    }

    public static JobExecutionSummary finishJob() {
        JobExecutionSummary summary = CURRENT_JOB.get();
        CURRENT_JOB.remove();
        return summary;
    }

    @Around("@annotation(trackStep)")
    public Object profileStep(ProceedingJoinPoint joinPoint, TrackStep trackStep) throws Throwable {
        JobExecutionSummary summary = CURRENT_JOB.get();
        long start = System.currentTimeMillis();
        String stepName = trackStep.value().isEmpty() 
            ? joinPoint.getSignature().getName() 
            : trackStep.value();

        try {
            Object result = joinPoint.proceed();
            long duration = System.currentTimeMillis() - start;
            if (summary != null) {
                summary.recordStep(stepName, duration, "SUCCESS", null);
            }
            return result;
        } catch (Throwable ex) {
            long duration = System.currentTimeMillis() - start;
            if (summary != null) {
                summary.recordStep(stepName, duration, "FAILED", ex.getClass().getSimpleName() + ": " + ex.getMessage());
            }
            throw ex;
        }
    }

    public static void logSummary() {
        JobExecutionSummary summary = finishJob();
        if (summary != null) {
            summary.complete();
            try {
                log.info("JOB_METRICS_SUMMARY: {}", OBJECT_MAPPER.writeValueAsString(summary));
            } catch (Exception e) {
                log.error("Failed to serialize job execution summary", e);
            }
        }
    }
}

```

### Step 4: Annotate Pipeline Service Methods

```java
@Service
public class DocumentPipelineService {

    @TrackStep("DOC_AI_LAYOUT")
    public LayoutResponse processLayout(File file) {
        // Business logic
    }

    @TrackStep("LLM_PAGE_EXTRACTION")
    public String processLlmPage(PagePayload payload) {
        // Spring AI call
    }

    public void executePipeline(String docId, String clientId, String useCaseId) {
        try {
            JobTracingAspect.startJob(docId, clientId, useCaseId);
            // Execute step sequence
        } finally {
            JobTracingAspect.logSummary(); // Outputs single-line JSON log
        }
    }
}
```
