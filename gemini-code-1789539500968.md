# Service 2 Refactoring & Production Readiness Specification

## Executive Summary
This document specifies the Phase 1 stability fixes and architectural roadmap for **Service 2**. The goal is to safely process **50–60 documents/hour** across **4–5 OpenShift (OCP) Pods** (500m–700m CPU request / 8 vCPU limit, 5 GiB RAM limit per pod) without triggering Kubernetes Out-Of-Memory (`OOMKilled`) crashes, OkHttp connection bottlenecks, or thread starvation.

---

## System Architecture & Capacity Limits

* **Pipeline Sequence:** S3 File → Service 1 → Stream to Service 2 → Doc AI Layout Batch → Doc AI OCR Batch → PDFBox Page Split → Layout JSON Page Split → Parallel Spring AI 2.0.1 Calls (30–40 pages) → External Python Overlay HTTP Service → Aggregate Pages → MongoDB Save + Response.
* **Latency Envelope:** ~10–12 minutes total duration per document.
* **Resource Allocations per OCP Pod:** 
  * **CPU Request / Limit:** 500m / 8 vCPU (Bursts allowed for PDF splitting/overlays)
  * **Memory Request / Limit:** 5 GiB / 5 GiB
  * **JVM Memory Floor:** `-Xmx3500m -Xms3500m` (Leaves ~1.5 GiB for non-heap, Metaspace, and OS)
  * **Pod Concurrency Limit:** **3 active documents** (or ~100 in-flight pages) maximum per pod.
  * **Cluster Throughput:** 5 Pods × 3 slots = 15 active jobs ≈ **55–60 docs/hour**.

---

## Phase 1: Production Survival (Immediate Implementation)

### 1. Spring AI 2.0.1 OkHttp Dispatcher Customization
**Issue:** Spring AI 2.0.1 utilizes OpenAI's Java SDK over OkHttp. OkHttp defaults to `maxRequestsPerHost = 5`, forcing 30 parallel page requests into 6 sequential batches (adding ~10 minutes of artificial delay).  
**Fix:** Uncap the OkHttp dispatcher host limit via `OpenAiHttpClientBuilderCustomizer`.

```java
package com.example.config;

import okhttp3.Dispatcher;
import org.springframework.ai.autoconfigure.openai.OpenAiHttpClientBuilderCustomizer;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class OkHttpConfig {

    @Bean
    public OpenAiHttpClientBuilderCustomizer customOkHttpDispatcher() {
        return builder -> {
            Dispatcher dispatcher = new Dispatcher();
            dispatcher.setMaxRequests(300);
            dispatcher.setMaxRequestsPerHost(150); // Unlocks parallel LLM calls to same host
            builder.dispatcher(dispatcher);
        };
    }
}
